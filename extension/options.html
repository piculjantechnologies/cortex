Cortex

Click the Cortex button in the toolbar on any page to see Cortex's object detections and label-quality scores on its images. Images Cortex does not have yet can be sent for analysis. The extension uses your Cortex login: log in on the Cortex web app first.

Where the extension sends its requests: the server that answers /api/…, usually the address of the Cortex web app.

Opened by "Open Cortex" when you need to log in; empty means the API URL. For a local setup: API http://localhost:5000, web app http://localhost:3000.

Privacy

The extension does nothing until you click its button. Then it sends the addresses of the page's images (not the page's address) to the Cortex API above, with your Cortex login. "Analyse" adds the image's address to the Cortex collection, where Cortex's pipeline downloads and analyses it like any other collected image.
